ВЕТКЛИНИКА — лабораторная работа 2

Что сохранено из исходного дизайна:
- Manrope
- цвета #F3F3F3, #191A23, #B9FF66
- исходная картинка с питомцами cats_dogs.png
- лапа paw.png
- градиентное растворение фото на карточках услуг
- карточки врачей с нижней тенью
- светло-серая форма записи с зелёным оформлением изображения
- тёмный footer

Структура:
index.html
service.html
doctors.html
appointments.html

css/
  style.css — подключает все CSS-модули
  base.css
  layout.css
  components.css
  home.css
  services.css
  doctors.css
  appointment.css
  responsive.css

js/
  main.js — бургер + модальные окна
  services.js — раскрывающиеся прайс-листы
  forms.js — проверка паролей и демонстрационная отправка форм

ВАЖНО:
Папка images содержит доступные в чате paw.png и cats_dogs.png.
Остальные ваши фотографии в чат отдельно не загружались. Сохраните вашу текущую папку images
или скопируйте перечисленные в images/README-images.txt файлы в этот проект.

Требования лабораторной:
- 4 страницы
- 3 категории услуг по 3 услуги
- Flexbox + Grid
- таблицы с thead/tbody/th/td/scope
- ul + ol
- alt у изображений
- БЭМ
- регистрация, авторизация, обратная связь
- HTML5 validation
- карта
- бургер с ARIA
- адаптив mobile/tablet/desktop
